# CodeAlpha_PhishingAwareness

An interactive web-based **Phishing Awareness Training & Assessment Module** created for the **CodeAlpha Cyber Security Internship**.

## Modules Included
- **Overview & Red Flags:** Identifying phishing emails, lookalike/typosquatting domains, and fake login pages.
- **Social Engineering:** Breakdown of urgency/fear, authority impersonation, bait, pretexting, quid pro quo, and spear/clone phishing.
- **Best Practices:** Practical prevention steps and incident response actions if a user clicks or shares credentials.
- **Interactive Quiz:** Scenario-based questions with instant scoring and explanations.

## How to Run
Open `index.html` directly in any modern web browser.
